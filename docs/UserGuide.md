# CamCapture 用户操作说明

## 安装

打开 `Installer` 文件夹，双击 `CamCapture_Setup_v2.0.2.exe`。选择安装位置后，安装器会创建 `CamCapture` 文件夹并生成快捷方式。

安装包已包含 .NET 8 Windows x64 运行支撑，目标电脑无需联网或单独安装 .NET。

## 启动

推荐双击桌面的 `CamCapture` 快捷方式。目录版也可以：

- 双击 `Program/CamCapture.exe`
- 运行 `Launcher/Start CamCapture.ps1`

## 界面说明

程序包含“功能总览”“相机抓图”“TCP 结果监听”和“压力监控”页面。相机抓图与 TCP 监听独立运行，任一功能停止或断线不会影响另一功能。

“压力监控”页每 5 秒读取运行参数与日志，显示内存、磁盘剩余、日志总量和增长速度、抓图数量、最近抓图时间与 NG 数量。发现抓图断档、写入队列满、保存失败、SDK/TCP 异常等问题时，会显示对应参数、报警阈值和处理建议。

进行 24H 压力测试时，应持续查看“压力监控”页。出现严重报警时，优先处理磁盘不足、抓图断档、写入队列满和 SDK 异常。程序日志默认自动清理超过 14 天的文件。

长期运行建议保持“简洁”日志模式，该模式只持久化关键状态与异常；切换为“详细”模式后会记录每次抓图步骤和完整结果，日志增长速度会明显增加。

“功能总览”是程序默认主页，使用大字体显示相机抓图服务与 TCP 结果监听服务的运行状态，并可直接开启或停止两个功能。主页不显示初始设置。

相机 IP、密码、存储保存天数、自动抓图间隔和启动选项均在“相机抓图”页设置。完成设置后点击“保存初始设置”，程序会更新 `Config/startup-config.json`。默认勾选启动程序后自动触发相机抓图、自动连接 TCP 通讯，并在自动启动完成后最小化窗口。

`Config` 文件夹专门存放初始配置。`default-camera-config.json` 是默认模板，`startup-config.json` 是程序下次启动时自动载入的现场配置。旧版本的 `Data/startup-config.json` 会在首次启动时自动迁移到 `Config`。

每台相机最上方是“相机状态”：

- `开启相机抓图`：连接相机并自动开始持续抓图。
- `停止相机抓图`：停止持续抓图并断开相机。
- `调试`：执行一次调试抓图。

“常用设置”包含 IP、用户名、密码、相机文件夹、存储文件夹和图片自动清理策略。处理文件夹按张数保留最新图片，存储文件夹按保存天数清理，两种策略可独立启用。

处理文件夹、自动抓图间隔、通讯端口、图片规格、手动触发和 IO 参数位于默认折叠的“高级设置”中。

## 默认设置

- IP：`192.168.1.68`
- 用户名：`admin`
- 最大图片张数：`5`
- 自动抓图间隔：`100ms`
- 默认处理文件夹：`Data/processing`
- 默认存储文件夹：`Data/storage`
- 默认存储时间：`90 天`

处理文件夹图片张数限制默认启用，默认保留最新 `5` 张 JPG/JPEG 图片。程序每分钟及每次抓图保存后递归统计处理文件夹，并按最后写入时间删除最旧图片，直到图片总数不超过自定义上限。

按天自动清理可选择任意存储文件夹，并设置存储天数。启用并连接相机后，程序每分钟及每次抓图保存后都会检查所选文件夹，递归删除超过存储天数的 JPG/JPEG 图片。

## TCP 结果监听

“TCP 结果监听”页面用于主动连接 VisionMarker TCP 服务，接收结果报文并播放 OK 或 NG 提示音。程序只接收数据，不向服务端回发消息。

1. 填写 VisionMarker 服务端地址和端口。
2. 根据报文格式选择解析模式。
3. 点击“启动连接”。
4. 收到独立的 `OK` 或 `NG` 结果后，页面更新统计并播放对应提示音。

“单次音频时长(ms)”用于限制每次 OK/NG 提示音的播放时长，可设置 `100–30000ms`，默认 `1500ms`。新结果到达时会立即播放新提示音，并重新计算停止时间。

支持以下解析模式：

- `整条报文扫描`：适用于报文格式不固定的情况。
- `按字段序号`：例如 `SN123,OK,20260613`，分隔符填写 `,`，结果字段序号填写 `2`。
- `按键值对`：例如 `barcode=SN123 result=NG station=A01`，结果键名填写 `result`。

连接断开后程序按照 `1秒、2秒、5秒、10秒、30秒` 的间隔自动重连。TCP 半包会先缓冲；没有换行符的短报文在默认空闲 `150ms` 后按完整消息处理。当同一结果同时包含 OK 和 NG 时，优先判定为 NG。

默认提示音位于：

- `Program/Media/ResultOK.wav`
- `Program/Media/ResultNG.wav`

## 长时间运行建议

程序已针对每天连续运行 12 小时进行以下处理：

- TCP 断线自动重连，并修正无换行残包的空闲补帧读取。
- 相机抓图使用异步写入队列，避免阻塞触发回调。
- 界面日志自动限制内存占用；完整日志继续按天写入 `Data/Logs`。
- 图片清理任务每分钟执行一次；处理文件夹通过张数上限控制，存储文件夹通过保存天数控制。

建议 Windows 关闭自动睡眠，并确保处理文件夹和日志磁盘保留足够空间。

## 文件夹说明

- `Program`：主程序、图标与提示音。
- `Config`：默认模板与已保存的初始配置。
- `Dependencies`：相机 SDK 依赖。
- `Launcher`：启动脚本。
- `Installer`：安装程序。
- `Data/processing`：相机抓图处理文件。
- `Data/storage`：需要按存储天数自动清理的图片。
- `Data/Logs`：程序运行日志。
- `Data/SdkLog`：相机 SDK 日志。
- `Docs`：使用和工程说明。

## 常见问题

### 无法连接相机

检查相机 IP、端口、用户名和密码，确认电脑与相机网络互通。

### 点击抓图没有图片

确认相机已连接，检查处理文件夹是否可写，并查看 `Data/Logs` 中的日志。

### SDK 调用失败

确认 `Dependencies/native` 文件完整，并查看 `Data/SdkLog` 和 `Data/startup.log`。

### 图片不断被删除

检查是否启用了处理文件夹图片数量限制或存储文件夹按天自动清理。处理文件夹默认仅保留最新 `5` 张，按天自动清理默认关闭，默认存储时间为 `90 天`。
